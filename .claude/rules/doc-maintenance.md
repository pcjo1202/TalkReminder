## 문서 업데이트 원칙

CLAUDE.md는 매 메시지마다 전체 로드된다. 토큰 예산을 의식하고 간결하게 유지한다.

## 업데이트 트리거 — 이 조건일 때만 문서 변경을 제안한다

- 새 FSD 슬라이스 추가 → 해당 레이어 CLAUDE.md 반영
- 새 환경 변수/시크릿 추가 → 관련 docs 또는 CLAUDE.md 반영
- 새 패키지 의존성 추가 → CLAUDE.md 기술 스택 반영
- package.json 스크립트 변경 → CLAUDE.md 명령어 섹션 반영
- 기존 rules와 충돌하는 새 패턴 채택 → 해당 rules 파일 업데이트
- 코드 리뷰에서 문서화되지 않은 컨벤션 발견 → Gotchas 또는 rules 추가

## 업데이트하지 않을 때

- 일상적 기능 개발, 버그 수정 — 문서 건드리지 않는다
- 코드에서 직접 읽을 수 있는 내용 — 문서화하지 않는다
- 일회성 디버깅/트러블슈팅 기록 — 문서에 남기지 않는다
- Claude가 지시 없이도 올바르게 수행하는 내용 — 규칙으로 작성하지 않는다

## 업데이트 방법

- 문서를 직접 수정하지 않고 변경 내용을 제안한다 — 사용자 승인 후 적용
- 한 항목당 한 줄 원칙. 명령어는 copy-paste 가능한 형태로
- CLAUDE.md와 rules 간 중복 금지 — 한 곳에만 작성

## 부패 감지

작업 중 아래를 발견하면 사용자에게 알린다:

- CLAUDE.md/rules에 참조된 파일 경로가 실제로 존재하지 않을 때
- 문서화된 명령어가 실행 시 실패할 때
- rules의 코드 예시가 현재 코드 패턴과 불일치할 때
